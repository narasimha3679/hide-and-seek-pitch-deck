# Hide and Seek - Producer Pitch Site

A single page, scroll driven pitch site for Harsha Muvva's psychological crime thriller, Hide and Seek. Built from the original pitch deck, with the story condensed for a production house reader.

## What is inside

- `index.html` - the whole site, one page
- `styles.css` - gold on black design, custom cursor, spotlight, parallax, reveal animations
- `script.js` - no libraries, no build step, no backend
- `assets/` - deck artwork optimised to WebP, about 1.5 MB total (the source PDF is 27 MB)

## Before you send the link

1. Replace `CONTACT_EMAIL` in `index.html` with Harsha's real email. Search the file for that one placeholder.
2. Check the director credit and the contact button once, then deploy.

## Deploy, any of these, no code changes needed

- Vercel: drag this folder into vercel.com/new, or run `vercel` in this folder
- Netlify: drag this folder into app.netlify.com/drop
- GitHub Pages: push this folder to a repo, then Settings, Pages, Deploy from branch, root folder
- Any static host: upload the files as they are, keeping `assets/` next to `index.html`

## Notes for the producer version

- The full twist is behind a "Reveal the truth" click, so the reveal still lands even in a private pitch.
- Tone is described in words only. The deck's Prestige and Don't Breathe stills and posters are not included, so this version is safe to share as a link.
- Reduced motion and touch devices are handled: the custom cursor and heavy animation turn off, the story still reads cleanly.
